challengetouch-next-linux

ベネッセ「チャレンジタッチ NEXT」（TAB-A05-BA1 / MediaTek MT8168）で、Android を消さずに Linux を動かす

これは Web 上で動作するコンテンツではありません。実機に Linux を入れるための手順と一式なので、 ここでは概要だけ説明します。手順・ビルドスクリプト・カーネルパッチは GitHub で公開しています（README だけで第三者が再現できるように書いています）。

概要

Android の boot パーティションは無傷のまま、recovery スロットに自作の Linux（Alpine + GNOME Flashback）を焼き、microSD を永続 rootfs として使う構成です。 電源を入れると Linux が起動し、Android に戻したいときは端末上のコマンドで戻せます。

できること

  • 電源投入だけで Linux（GNOME Flashback デスクトップ）が自動起動
  • USB 経由で操作（RNDIS ネットワーク + SSH + ACM シリアル）
  • オンスクリーンキーボード（onboard）で文字入力、タッチ／ペン対応
  • デスクトップのメニューからシャットダウン／再起動（充電器接続中は仕様で起動し直す点に注意）
  • 端末上のコマンドで Android へ復帰（boot は未変更なので壊れません）

仕組み

要素内容
起動スロットrecovery (p15) に Linux。boot (p14) は純正 Android のまま
起動の固定para (p16) の BCB に毎起動 boot-recovery を書き戻す
rootfsmicroSD 上の Alpine（リフラッシュ不要で編集できる）
カーネルMediaTek 4.14 downstream を自前ビルド（パッチは kernel/ に同梱）

現状・制約

  • 充電器を挿したままの電源OFF は、いったん消えるがハード仕様で勝手に起動し直す（USB を抜けば確実に切れる）
  • 内蔵 Wi-Fi は未対応（ドライバがベンダ提供の別リポジトリのため手元に無い）。ネットワークは USB 経由のみ
  • 内蔵スピーカーは調整中（音の経路は通っているが、SoC→コーデックのデジタルリンクが未確立）
