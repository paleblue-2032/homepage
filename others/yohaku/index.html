yohaku

Markdownプレビュー機能付きの、シンプルで機能美に優れたメモ帳エディタ

これは Web 上で動作するアプリではなく、Qt 6 / QML で書いたデスクトップアプリです。 ここでは概要だけ説明します。ビルド方法・ショートカット・設定は GitHub で公開しています。

余白を大切に、書くことだけに集中できるエディタ。

概要

Linux (Wayland / X11)・macOS・Windows で動く、たたき台ではなく常用できるメモ帳です。 標準ショートカットがそのまま効き、タブ・セッション復元・栞・検索・Markdown プレビューを備えています。 設定は ~/.config/yohaku/settings.json の 1 ファイルにまとまっていて、 テーマやアクセントカラー、キー割り当ても JSON で変更できます。

特徴

  • 標準ショートカットがそのまま効く（Ctrl+C / V / X / Z / S など）
  • タブ — 複数ファイルをタブで。Ctrl+T で新規、Ctrl+Tab で切替
  • セッション復元 — 終了時に開いていたタブを次回起動時に復元
  • 栞 — 自動（最後のカーソル位置）・手動（Ctrl+B）・ファイル栞（Ctrl+Shift+B）
  • 日本語入力 — fcitx5 などの IME からそのまま入力
  • テーマ & アクセントカラー — ダーク / ライト、5 色
  • 透過 — なし / 弱 / 中 / 強
  • Markdown プレビュー — GFM として解釈し、GitHub 風に整形（Ctrl+P、閲覧専用）

使い方

yohaku                      # 新しいノート
yohaku file.txt             # ファイルを開く
yohaku a.md b.txt           # 複数ファイルをタブで開く
yohaku --preview file.md    # Markdown プレビューで開く

すでに起動していれば、yohaku file は既存ウィンドウのタブとして開きます（単一インスタンス）。

インストール

ワンライナー（macOS / Linux）:

curl -fsSL https://raw.githubusercontent.com/paleblue-2032/yohaku/main/scripts/install.sh | bash

Nix（試すだけ）:

nix run github:paleblue-2032/yohaku

Releases に macOS / Windows / Linux 向けのビルド済み成果物もあります。

主なショートカット

キー動作
Ctrl+T / Ctrl+N新しいタブ
Ctrl+Oファイルを開く
Ctrl+Tab / Ctrl+PageDown次のタブ
Ctrl+S / Ctrl+Shift+S保存 / 名前を付けて保存
Ctrl+F検索（Enter 次、Esc 終了）
Ctrl+PMarkdown プレビュー切替
Ctrl+B / Ctrl+Shift+Bこの行に栞 / ファイル栞
Ctrl+W / Ctrl+Qタブを閉じる / 終了
