clappingcat_on_terminal

タイポしたら黒猫が拍手して煽ってくる、ターミナル用の小さなCLI。コマンド名は clpcat

これは Web 上で動くアプリではなく、ターミナルで動かす CLI です。 雰囲気だけでも伝わるように、実際に使っている ASCII フレームをそのままブラウザで再生しています。 本体は GitHub で公開しています。

ターミナルでは q / Esc / Ctrl-C で閉じられます

概要

存在しないコマンドを打つと、画面いっぱいに黒猫が現れてパチパチしながら煽ってきます。 モノクロの記号 ASCII で 1 フレームずつアニメーションします。 シェルの「コマンドが見つからない」フックに仕込むと、タイポのたびに確定で出てきます。

使い方

clpcat                # 猫が1回踊る
clpcat -n 3           # 3回繰り返す
clpcat -n 0           # 無限ループ（q で閉じる）
clpcat --fps 24       # 再生速度を上げる
オプション説明既定
-n, --repeat <N>再生回数（0 で無限ループ）1
--fps <FPS>再生速度（fps）12

再生中は q / Esc / Ctrl-C で閉じられます。

タイポで煽らせる

シェルの「コマンドが見つからない」フックに clpcat を仕込みます。

zsh（~/.zshrc）:

command_not_found_handler() {
  print -u2 "zsh: command not found: $1"
  if [[ -t 1 && -z "$CLPCAT_DISABLE" ]]; then
    clpcat
  fi
  return 127
}

bash（~/.bashrc）:

command_not_found_handle() {
  echo "bash: $1: command not found" >&2
  if [ -t 1 ] && [ -z "$CLPCAT_DISABLE" ]; then
    clpcat
  fi
  return 127
}

CLPCAT_DISABLE を立てておくと自動再生を止められます（export CLPCAT_DISABLE=1）。

インストール

Nix（ワンオフ実行）:

nix run github:paleblue-2032/clappingcat_on_terminal

プリビルドバイナリ（Linux / musl 静的リンク）:

curl -fsSL https://raw.githubusercontent.com/paleblue-2032/clappingcat_on_terminal/main/scripts/install.sh | bash

仕組み

  • 元動画を ffmpeg で間引き・グレースケール化し、Python で輝度を ASCII ランプへ写像して assets/frames.txt を生成
  • frames.txt はバイナリに include_str! で埋め込み（実行時に動画も ffmpeg も不要）
  • crossterm でオルタネートスクリーンに中央寄せしてフレームを描画
