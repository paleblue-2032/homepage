connpass_check-in-system

connpassの受付で使う、QRコードによる出席管理システム（Google Apps Script）

これはWeb上で動作するコンテンツではありません。Googleスプレッドシートに紐づけた Apps Script として設置して使うツールなので、ここでは導入手順だけを説明します。 ソースコードは GitHub で公開しています。

できること

  • 参加者のQRコードを端末カメラで読み取り、出席とチェックイン時刻を自動で記録
  • 交通費補助の対象者を、読み取り時と一覧の両方で表示
  • チェックイン済み／未チェックインの状況を一覧で確認（2秒ごとに自動更新）

ファイル構成

ファイル役割
Code.gsサーバー側処理（参加者の検索・記録・状況集計）
Index.html受付端末の画面（QR読み取り／状況確認）

Code.gs は getActiveSpreadsheet() を使うため、必ず スプレッドシートに紐づけた Apps Script（拡張機能 → Apps Script）として設置します。 単体の Apps Script プロジェクトでは動作しません。

スプレッドシートの準備

シート名 「参加者リスト」 を用意し、1行目をヘッダーとして次の列構成にします。

列内容備考
A登録番号QRコードから読み取る値と一致させる
B名前受付画面・一覧に表示
Cステータスチェックイン時に「出席済み」を自動記入
Dチェックイン時刻チェックイン時に HH:mm:ss を自動記入
E交通費補助の有無「あり」のとき補助対象として扱う
  • データは 2行目以降 を対象とします（1行目はヘッダー）。
  • C・D列は空欄で構いません（自動で書き込まれます）。
  • connpassからダウンロードした参加者CSVをインポートし、A列（登録番号）とB列（名前）に配置します。E列の交通費補助は対象者に手入力します。

セットアップ手順

  1. Googleスプレッドシートを新規作成（または既存を利用）
  2. シート「参加者リスト」を作成し、上記の列構成にする
  3. connpassのCSVをインポートしてA・B列を配置
  4. メニューの「拡張機能」→「Apps Script」を開く
  5. Code.gs の内容をエディタのコードへ貼り付ける
  6. エディタ左の「＋」→「HTML」でファイルを作成し、名前を Index にする（拡張子は付けない）。Index.html の内容を貼り付ける
  7. 保存する
  8. 「デプロイ」→「新しいデプロイ」→ 種類で「ウェブアプリ」を選択
    • 実行ユーザー: 自分
    • アクセスできるユーザー: 受付端末から開ける範囲で設定（例: 全員）
  9. 「デプロイ」を押し、初回は表示される権限の承認を行う
  10. 発行された ウェブアプリのURL を受付端末のブラウザで開く

受付時の操作

  1. 受付端末でウェブアプリのURLを開く
  2. 「QRコードでチェックイン」を選択
  3. カメラの使用を許可し、参加者のQRコードをかざす
  4. 画面に名前・結果と補助の有無が表示される

別端末で「チェックイン状況を確認」を開くと、随時最新の状況を確認できます。

注意事項

  • スプレッドシートに紐づいた状態でのみ動作します。
  • カメラを使用するため、ブラウザで開けるHTTPS環境が必要です（GASのウェブアプリはHTTPSで提供されます）。
  • QRの登録番号はURL末尾から1つ前のパス要素を取り出して判定しています。connpassのQR形式が変わった場合は extractRegisteredId() の調整が必要です。
  • 状況確認モードは2秒間隔でサーバーに問い合わせるため、多数の端末で同時に開くと負荷が増えます。
